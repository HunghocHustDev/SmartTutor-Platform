# Frontend

Frontend cua SmartTutor Platform, xay dung bang React + Vite.

## Chay dev server

```powershell
npm install
npm run dev
```

## Build

```powershell
npm run build
```

## Ghi chu

- Frontend hien tai chua goi backend that.
- Du lieu dang nam trong mock data/local state.
- API contract de noi backend nam o `../docs/frontend_api_contract.md`.
